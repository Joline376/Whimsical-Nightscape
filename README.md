# Whimsical-Nightscape
The concept of my design was to create an interactive visual experience showcasing nighttime scenery. Moreover, I wanted to create an aesthetic showcasing nature, animals and the sky to create a lively, warm feeling and captivating visual appearance for the users. The game Animal Crossing inspired me when I did this assessment. In Animal Crossing, users can customize their environment and character. In addition, I aim to incorporate similar features and user interaction into my code to enable users to personalize their own experience and influence system outcomes. This design will allow users to personalize and influence the landscape to create an experience that highlights the beauty of nature. The provided code is generative because it generates visual design using random, lerp and noise function leading to few outputs. According to Monro (2009), the theory of generative-art emergence is unpredictable and evokes the feelings of surprise-wonder-mystery-autonomy. In the context of generative design, this can be stated that creating systems with outcomes that stay unpredictable and inspire amazement can emphasize their emotional impact as well as autonomy.  

The mouse movement represents the movement of a ladybug flying around. Additionally, I wanted to capture the charm of nature and immersive experience. Once the ladybug mouse is pressed from the bottom half of the canvas, flowers will grow from the ground. However, it will reverse its growth transition in which it will go back to its original state if the ladybug mouse is pressed on the flower. I also added the random color, loop function, stem height, changes between the petals and the sizes of petals to showcase a different appearance and colorful display every time a flower appears. The mouse can also control the amount of shooting stars appearing in the sky to add a magical and whimsical element when users interact with the upper half of the canvas. It was inspired by one of the scenes in Animal Crossing where the players start making wishes upon the shooting stars across the night sky. It is something I remember for a very long time since it brought nostalgia and fond memories because I enjoyed this game since I was a child. The background music ‘Night’ by Lukrembo will be played as the code is run to add a soothing and calming vibe to the scene. Additionally, I wanted to showcase a mountain in the scenery to enhance the overall atmosphere and aesthetic appeal for the users by using the noise function and making it look like an illusion of movement happening. I have also included some particles in the background to make it look like there are stars or movement in the night sky. There were some errors in the code because of wrong input, variable names, audio file being too big and error in transition. However, it took a long time and I have fixed the code by changing it, using a for loop, adding a few functions and class to make it work the way I want it to.
